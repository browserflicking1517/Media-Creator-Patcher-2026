### Why does my anticomponent flag videopatch.exe?

Some security tools may flag patching utilities as Potentially Unwanted Programs (PUPs) due to their nature of modifying software. This is a common false positive. You may need to add an exclusion.

It supports CapCut, DaVinci Resolve, Filmora, VideoPad, HitFilm, and Movavi. Check the repository for updates on future support.

### Will this work on my Mac or Linux system?

VideoPatch is designed exclusively for Windows desktop environments and is not compatible with macOS or Linux operating systems.

### Do I need to have the video editor installed first?

Yes, VideoPatch must be applied to a valid, existing installation of one of the supported video editing applications.

### Will the patch persist after I update the video editor?

Generally, major updates from the software developer may overwrite the patch, requiring you to re-apply it. Minor updates may not affect it.

### What should I do if the patch fails?

Ensure you have the correct version of the video editor, run videopatch.exe as Administrator, and temporarily disable any running instances of the editor. Check the FAQ in the repository for specific error codes.
